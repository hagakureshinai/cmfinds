# CMFinds トップページの一時比較プレビュー

`index.html`をブラウザーで開くと、現状・エディトリアル型・洗練カード型を比較できます。「PC幅 1024px」「スマホ幅 390px」で切り替えてください。各画面内をスクロールでき、「単独で開く」から通常サイズでも確認できます。

ローカルサーバーを使う場合は、リポジトリのルートで実行します。

```powershell
node .tmp-home-design/serve.mjs
```

http://127.0.0.1:4322/ を開いてください。終了はCtrl+Cです。サーバーを使わず、`index.html`を直接開く方法でも比較できます。

`generate.mjs`は公開中の4記事のタイトル・説明文・slugを読み取り、現在のCSSをこのフォルダーにコピーします。再生成する場合は `node .tmp-home-design/generate.mjs` を実行します。

`comparison-1024.png`と`comparison-390.png`は比較画面のスクリーンショットです。各案の全体画像は`current-*.png`、`editorial-*.png`、`refined-*.png`です。

すべてAstroの`src/`・`public/`外に置いた一時作業物です。本番ビルドには入りません。計測スクリプト・外部画像・追加パッケージは使っていません。記事見出しのリンク先は既存のローカルAstroサーバー（4321番ポート）です。

本番のトップページ・レイアウト・記事・計測設定は変更していません。比較が不要になったら、この`.tmp-home-design/`フォルダー全体を削除できます。
